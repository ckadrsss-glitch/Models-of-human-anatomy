# Бренд в V2 (CK BIOMECHANICS)

Реализация — `src/brand.js`.

| Элемент | V2 |
|---|---|
| Верхний титр | **CK BIOMECHANICS** — как во всех роликах серии (ck-incisor-intrusion): Inter 500, 28 px, трекинг 10.4 px, базовая линия 212.5 px, `#eef2f7`, мягкая тень. Виден весь ролик, растворяется вместе с содержимым в начале концовки |

| Логотип | CK внутри **тонкого** круга (обводка 3.5 px, `#2de2d0`), ниже BIOMECHANICS; геометрия, шрифты и отступы — как в бренд-ките серии |
| Концовка | последние 3 с: растворение содержимого 0–0.9 с, круг с CK 0.55–1.35 с, BIOMECHANICS 1.15–1.95 с, статичный финальный кадр |
