# Björk–Jarabak V2 — научная основа, модель и проверка

## 1. Определения точек (как в ролике и в коде)

| Точка | Определение | Как строится в модели (`src/morph.js → ceph()`) |
|---|---|---|
| **S** — Sella | центр турецкого седла | фиксированная точка в центре гипофизарной ямки исходного черепа |
| **N** — Nasion | наиболее передняя точка лобно-носового шва | фиксирована |
| **Ar** — Articulare | **рентгенологическая конструктивная точка**: пересечение заднего контура мыщелкового отростка с нижним контуром основания черепа (basi-occiput). Не центр головки мыщелка | пересечение двух контуров проекции; пересчитывается в каждом кадре |
| **Go** — Gonion | конструированный: касательная к заднему краю ветви через Ar и касательная к нижнему краю тела; биссектриса угла между ними пересекает контур челюсти | одна и та же методика для всех моделей; точное пересечение биссектрисы с контуром |
| **Me** — Menton | самая нижняя точка костного симфиза | минимум нижнего контура симфиза |
| **Pog** — Pogonion | самая передняя точка подбородка (по направлению S–N) | используется только для показа проекции подбородка в сценах 01 и 03 |

Все углы и расстояния вычисляются по координатам этих точек в **ортографической строго боковой проекции**
(обе половины челюсти наложены, как на ТРГ). Перспективы нет. Числа на экране — округления измеренных значений;
в сцене 06 суммы — сумма показанных целых чисел (совпадает с точной суммой ≤ 0.05°).

Контуры (`tools/contours.py → src/contours.js`): задний край мыщелка и ветви, нижний край тела, передний край
симфиза, нижний контур основания черепа. Те же точки деформируются той же функцией, что и сетка в шейдере, —
линии, дуги и числа всегда лежат на изображённой кости.

## 2. Модель морфологии

Один анатомический череп Z-Anatomy / BodyParts3D (взрослый мужчина). Варианты — параметрические деформации,
а не сканы пациентов. Параметры (все — измеримые морфологические компоненты, без вертикального масштабирования черепа):

| Параметр | Что меняет |
|---|---|
| `sad` | поворот вокруг S заднего основания черепа (суставные ямки, область Ar) вместе с нижней челюстью → только седловидный угол |
| `pcb` | длина заднего основания черепа S–Ar |
| `rot` | поворот нижней челюсти вокруг оси головки мыщелка → артикулярный угол (ориентация ветви) |
| `ramus` | высота ветви |
| `bend` | гониальный угол (изгиб тела вокруг гониона) |
| `body` | длина тела нижней челюсти |
| `sym`, `notch` | высота симфиза, антегониальная вырезка |

Верхний зубоальвеолярный отросток следует за нижним зубным рядом → **окклюзия сохраняется во всех моделях**
(вертикальный паттерн не изображается через открытый прикус). Коронки жёсткие, корни следуют альвеолярной кости.
Область основания черепа вокруг суставной ямки деформируется плавно (вес 1 до 12 мм от центра, 0 после 34 мм).

**Масштаб.** Исходный череп мал (S–N = 65.8 мм). Весь образец равномерно масштабирован относительно S
(×1.0787), чтобы S–N = 71 мм, как в выбранной норме. Углы и соотношения от масштаба не зависят; все линейные
значения на экране измерены на масштабированной модели.

## 3. Выбранная система референсов и найденные расхождения

| Показатель | Референс в ролике |
|---|---|
| N–S–Ar (saddle) | 123° ± 5° |
| S–Ar–Go (articular) | 143° ± 6° |
| Ar–Go–Me (gonial) | 130° ± 7° |
| Björk sum | 396° ± 6° |
| upper gonial Ar–Go–N / lower N–Go–Me | 52–55° / 70–75° |
| S–N / S–Ar / Ar–Go / Go–Me | 71 ± 3 / 32 ± 3 / 44 ± 5 / 71 ± 5 мм |
| Jarabak ratio S–Go/N–Me | **62–65 %** (учебный референс, указанный в ТЗ) |

**Расхождение 1 — пример «74 / 116 × 100 = 63.8 %».** Многоугольник N–S–Ar–Go–Me полностью определяется
S–N, S–Ar, Ar–Go, Go–Me и тремя углами. При точных нормах 123°/143°/130° и S–N = Go–Me = 71 мм, если N–Me = 116 мм,
то S–Go неизбежно ≈ 72 мм (62.3 %), а при S–Go = 74 мм N–Me ≈ 118 мм. Пример 74/116 несовместим с остальными нормами.
Выбор: сохранить **точные угловые нормы** (их складывают на экране в сцене 06) и **соотношение 63.8 %**;
миллиметры показываются измеренные на модели: **77.0 / 120.7 × 100 = 63.8 %** (S–Ar 33.5, Ar–Go 47.6 мм — в нормах).

**Расхождение 2 — верхний/нижний гониальный угол.** При тех же нормах и S–Ar в пределах 32 ± 3 мм верхний угол
получается 52.7° (в диапазоне), а нижний — 52.7 + x = 130 → **77.3°**, т. е. на 2.3° выше учебного диапазона 70–75°.
Чтобы получить нижний ≤ 75°, нужен S–Ar ≈ 43 мм (вне нормы). На экране показано честно: «77.3° · ref 70–75°».

**Расхождение 3 — границы Jarabak ratio.** В литературе встречаются разные границы (54–58 / 59–63 / 64–80 %,
< 59 / 59–63 / > 63 %, < 62 / 62–65 / > 65 %). В V2 по ТЗ используется 62–65 % как учебный референс нормы;
это подписано на экране («teaching reference»), и примеры 56 % / 64 % / 68 % лежат однозначно вне/внутри него.

## 5. Что в ролике сознательно НЕ утверждается

* одна ТРГ не прогнозирует скорость и направление роста (стрелки CW/CCW подписаны как морфологическая тенденция);
* правило «Go–Me больше S–N на 3–5 мм» не используется;
* скелетный класс не определяется по длине тела челюсти (подпись в сцене 07) и не смешивается с вертикальным паттерном (сцена 09);
* нормы не подаются как универсальные: «Reference values depend on age and population. Morphology ≠ growth prediction»;
* изменения седловидного угла — условные конфигурации, не результат лечения; модели A/B — иллюстративные, не клинические случаи.

## 7. Ограничения

* Один исходный индивидуум; модели — деформации. Вокруг суставной ямки — плавная деформация основания черепа
  (до ~6 мм в модели B), у верхней челюсти — следование зубного ряда за нижним (окклюзия сохранена).
* Конструированные точки по проекции 3D-модели ≈ ±0.5–1 мм; достаточно для учебной схемы, не для клиники.
* Мягкие ткани не показаны.
