## Протокол удержания (CK BIOMECHANICS Audience Retention Protocol)

| Элемент | Где |
|---|---|
| Visual hook | кадр 0: два черепа, на обоих уже видна линия Go–Me 71 mm — понятно без звука |
| Triple hook | 1) визуальный контраст профилей · 2) «SAME LENGTH / 71 mm = 71 mm» · 3) вопрос «почему разные профили?» + подсвеченная разница подбородка (12 mm) |
| Curiosity gap | ответ не раскрывается до сцены 10 |
| Dopamine loop | каждые 1–3 с новое событие: точка, линия, дуга, число, сравнение, морфинг |
| Mid-video rehook | 31.3 с «Но знаете, в чём подвох?» — музыка почти исчезает, затем SAME SUM → DIFFERENT ANATOMY с акцентами |
| Visual payoff | сцена 10: те же два черепа, последовательная подсветка компонентов |
| Кинетическая типографика | ключевые слова на моменте произнесения (`src/kinetic.js`), английский термин + короткое русское пояснение |
