# CK BIOMECHANICS — Incisor Intrusion: Three Force Application Points

Образовательная 3D-анимация (Three.js / WebGL) для Instagram Reels: **интрузия четырёх нижних резцов двумя кантилеверами
в трёхкомпонентной сегментарной механике**. ONE FORCE · THREE POINTS · THREE OUTCOMES: одна и та же результирующая сила,
три альтернативные точки подвязки кантилеверов (A — мезиально на секционной дуге, B — на продолжении на уровне ЦС,
C — дальше дистально) и три результата: интрузия с вестибулярным наклоном, чистая интрузия (идеализированно) и интрузия
с ретроклинацией. Показана реальная переподвязка: снять лигатуру → деактивировать → сместить крючок → реактивировать → подвязать.

Это переработка проекта `../ck-incisor-intrusion/` (версия с пятью точками сохранена там без изменений, включая её MP4).
**60 с · 9:16 · 1080 × 1920 · 30 fps · H.264 + AAC · ≤ 25 МБ.** Русская озвучка (ElevenLabs, голос **Принц Нури**),
английская научная типографика, русские субтитры.

## Запуск

```bash
cd ck-incisor-intrusion
node tools/serve.cjs 8123        # → http://localhost:8123/   (или python3 -m http.server)
```

Управление: ▶ / ❚❚ (пробел), ↺, ползунок, ←/→ — кадр (Shift — 1 с), кнопки сцен, 🔊 звук, 💬 субтитры (`?subs=0`),
`?t=30` — открыть на 30-й секунде.

## Производство (так собран файл в `export/`)

```bash
pip install numpy scipy scikit-image trimesh
python3 -I tools/build_assets.py      # дентиция Z-Anatomy → система дуги, ЦС сегмента, кость, точки A/B/C, позы, QA
node tools/qa.mjs                     # 102 проверки: зазоры (вкл. путь переподвязки), окклюзионная плоскость, знаки моментов, равновесие
node tools/qa_stills.cjs docs/qa      # контрольные изображения: конструкция, подвязка A/B/C, системы сил, траектории, реакции
node tools/build_audio.mjs            # музыка + саунд-дизайн + озвучка → микс −15 LUFS (assets/audio/mix.m4a)
node tools/render.cjs build/frames 4  # headless Chromium (SwiftShader) → 1800 JPEG-кадров (докачивает недостающие)
bash tools/encode.sh build/frames     # 2-проходный H.264 + AAC → export/…FINAL.mp4 (проверка ≤ 25 МБ)
node tools/make_srt.mjs               # SRT из таймингов
```

Перерендерить одну сцену: удалите её кадры из `build/frames` (кадр = t × 30) и снова запустите `render.cjs` — он дорисует
только недостающие кадры. Каждый кадр — чистая функция времени, поэтому плеер, перемотка и офлайн-рендер совпадают.

Озвучка: ElevenLabs, голос «Принц Нури» (`gJEfHTTiifXEDmO687lC`), `eleven_multilingual_v2`, по одному дублю на фразу (8 фраз).
Тексты — дословно из брифа. Тайминги слов получены транскрипцией ElevenLabs Scribe (`src/words.js`). Вся кинетическая
типографика и события анимации привязаны к фактическим словам озвучки (`src/timeline.js → W`).

## Честные оговорки

* **Приложенных фотографий и схем André Wilson Machado, а также материалов лектора в рабочем окружении нет**; их содержание
  не придумывалось. Геометрия ступенчатых продолжений и точек A / B / C восстановлена по публикациям (Caldas et al. 2014;
  de Brito et al. 2019; Elkholy et al. 2023). Правка — в одном месте (`tools/build_assets.py`).
* Полные тексты статей из окружения недоступны (PMC, MDPI, doi.org блокируются сетью); библиография сверена по записям поиска.
* Модель **качественная**: ЦС оценён (≈), амплитуды перемещений иллюстративные и умеренные. B даёт d ≈ 0 **в этой модели** и не
  является универсальной точкой чистой интрузии. Одинаковая F в трёх вариантах — допущение сравнения: при переносе точки
  подвязки кантилевер реактивируется (в кадре: «RE-ACTIVATE FOR THE SAME F»).
* Зубы BodyParts3D низкополигональные (сглажены подразделением Loop), это не КЛКТ конкретного пациента.
