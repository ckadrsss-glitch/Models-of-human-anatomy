## 6. Пассив и активация

Сцена 02: пассивная форма → введение в трубку → перемещение свободного конца к передней дуге (контур пассива + стрелка) →
упругий прогиб плеча (профиль консольной балки) → подвязка → F/2 + F/2 → F. Пассивный свободный конец гингивальнее точки
подвязки, активация поднимает его окклюзионно → кантилевер стремится вернуться и даёт интрузивную силу на передний сегмент.
Длины плеча L_A / L_B / L_C ≈ 43,7 / 25,8 / 22,7 мм; для сопоставимой F прогиб реактивируется δ ∝ L³ (4,6 / 0,95 / 0,65 мм,
иллюстративно). Амплитуды наклона: θ_A ≈ 8,0°, θ_B = 0, θ_C ≈ −3,5° (иллюстративно, увеличение — камерой).
