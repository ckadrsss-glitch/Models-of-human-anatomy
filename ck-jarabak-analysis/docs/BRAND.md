# Бренд CK ORTHODONTICS в этом проекте

Реализация — `src/brand.js`. Исходный бренд-кит CK BIOMECHANICS (`ck-skeletal-patterns/src/brand.js`) **не изменялся**;
здесь — отдельная копия.

| Элемент | Как сделано |
|---|---|
| Фон | без изменений из бренд-кита: радиальный градиент `#0a1730 → #06101f → #02060d`, холодное свечение `rgba(70,150,255,0.10)` на 46 % высоты; в Three.js подаётся как sRGB-текстура без тонмаппинга — одинаков во всём ролике и в концовке |
| Логотип | та же геометрия, что у CK BIOMECHANICS: круг r = 118 px, обводка 6 px `#2de2d0`, «CK» Montserrat 700 104 px; под кругом — **ORTHODONTICS** (одно слово, заглавные, Montserrat 600 58 px, разрядка 9 px, те же отступы) |
| Концовка (3 с) | та же анимация: 0–0.9 с растворение содержимого, 0.55–1.35 с круг с CK, 1.15–1.95 с ORTHODONTICS, затем статичный кадр |
| Верхняя надпись | **CK ORTHODONTIC** — см. ниже |

## Постоянная верхняя надпись — реконструкция по кадру

Исходного файла проекта с этой надписью в репозитории нет. Она восстановлена по кадру предыдущего ролика
`IMG_5338.png` (скриншот 1179×2556; видео занимает 1179×2096 от y = 230, масштаб к кадру 1080×1920 — 0.916):

| Параметр | Измерено на кадре | В проекте |
|---|---|---|
| Текст | CK ORTHODONTIC (без S на конце) | `CK ORTHODONTIC` |
| Горизонталь | ink-границы 364.6–714.5 px, центр 539.6 px | те же границы (разрядка подбирается автоматически под ширину) |
| Базовая линия | 212.5 px; высота заглавных ≈ 20 px | baseline 212.5 px, кегль 28 px |
| Цвет | ≈ `#eef2f7` | `#eef2f7` |
| Гарнитура | нео-гротеск средней насыщенности, широкая разрядка | **Inter Medium** (OFL) — ближайшее открытое соответствие |

Если у вас есть исходный файл (название шрифта, точная разрядка) — замените `TOP.font` и при необходимости
границы в `src/brand.js`; всё остальное подстроится.

Наблюдение: в верхней надписи старого ролика — ORTHODONTIC, а в новой заставке по ТЗ — ORTHODONTICS. Оставлено
ровно так, как указано («не изменяй текст» надписи; «ORTHODONTICS» в логотипе).
