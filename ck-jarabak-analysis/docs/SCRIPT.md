## Звук
* `assets/audio/voiceover.m4a` — отдельная дорожка озвучки (60 с, клипы на своих местах).
* `assets/audio/sfx.m4a` — негромкий технологичный саунд-дизайн (процедурный, без сторонней музыки).
* `assets/audio/mix.m4a` — финальный микс: SFX приглушаются под голосом (sidechain), −16.6 LUFS, true peak −1.5 dBTP.

## Замена озвучки готовой дорожкой
* В плеере: **♪ Импорт аудио** — выбранный файл (начинается с 00:00) играет вместо микса и попадает в запись WebM / экспорт MP4.
* Офлайн: `node tools/build_audio.mjs my_voiceover.wav` → пересобирает микс с вашей дорожкой; затем `bash tools/encode.sh`.
* Сдвинуть отдельные реплики: поменять `VOICE[].start` в `src/timeline.js` и пересобрать звук.
