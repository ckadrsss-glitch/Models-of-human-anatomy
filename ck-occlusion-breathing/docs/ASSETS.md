### Чего в репозитории нет

| Структура | Решение |
|---|---|
| **Молочные зубы** | Сгенерированы из постоянных коронок BodyParts3D (A,B ← резцы, C ← клык, D, E ← первый моляр), уменьшены (×0.6–0.76), корни укорочены, эмаль светлее. Размещены в позициях молочной дуги. |
| **Глоточная миндалина (аденоиды)** | Процедурная дольчатая форма (5–6 сагиттальных гребней с бороздами) на задне-верхней стенке носоглотки; положение снято по срединному сагиттальному срезу экспортированного черепа (`tools/sagittal_plot.py`). |
| **Нёбные миндалины (сцена 5, v2)** | Меш Z-Anatomy «Palatine tonsil» низкополигональный (86 вершин). Поэтому сделаны процедурные миндалины с криптами в латеральных стенках ротоглотки по тем же ориентирам; гипертрофия растёт медиально и оставляет просвет. |
| **Просвет дыхательных путей** | Сплайновые пути (ноздри → носовые ходы → хоаны → носоглотка → ротоглотка), подогнанные к тем же ориентирам; полупрозрачная «трубка» просвета + частицы. |
| **Детский череп** | В атласе только взрослый мужской череп. Применена плавная деформация: лицевой отдел укорочен по вертикали (до −14 %) и глубине (−7 %) относительно мозгового черепа. Это стилизация пропорций, а не модель конкретного возраста. |

### Внешние источники

Поиск дополнительных моделей был ограничен сетевой политикой окружения: Sketchfab, NIH 3D, Zenodo, архив BodyParts3D, Thingiverse, Hugging Face — заблокированы (HTTP 403 на прокси). Поэтому недостающие структуры построены процедурно (см. выше). Если позже появится доступ, кандидаты на замену:

* молочные зубы — University of Dundee School of Dentistry (CC BY 4.0, Sketchfab);
* глоточная миндалина/носоглотка — сегментации КТ/МРТ с открытой лицензией.

Подмена выполняется в `src/anatomy.js` (`_buildPrimary`) и `src/airway.js` (`Adenoid`).

## Видео-референс

`CK_BIOMECHANICS_reference_under11MB.MP4` (в ТЗ назван `…under25MB.mp4`; в репозитории лежит файл с этим именем), 510×1108, 89 с. Изучен по раскадровке (кадр каждые 3 с). Взяты только общие приёмы: полупрозрачные «стеклянные» кости, реалистичные зубы цвета слоновой кости, зачатки в кости, индикатор возраста, смена ракурсов сбоку / спереди / окклюзионно. Графика, подписи, цифры и кадры референса не использовались; возрастная шкала, вёрстка и логотип — собственные.
